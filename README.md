# Smart Energy Meter — 4Digitalca
### OhmSPRINT 2026

An energy monitoring project developed by team **4Digitalca** for the OhmSPRINT 2026 hackathon.

The system combines an **ATM90E26 metering IC**, an **ESP32 microcontroller**, and a **Vue-based web application** for wireless data visualization via Bluetooth.

The project aims to measure RMS voltage and current, frequency, active power, and energy consumption.

## Repository Contents

- **project_files/** — KiCad schematics, PCB layout, component libraries, BOM, and manufacturing files.
- **firmware/** — ESP32 firmware written in C using ESP-IDF.
- **web/** — Web application for displaying data and configuring update intervals.
